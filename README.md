# 🛒 Amazon Clone

A responsive Amazon clone built using HTML, CSS, and JavaScript. This project replicates the core user interface of an e-commerce website and focuses on layout design, responsiveness, and frontend development skills.

---

## 📌 About the Project

This project is a front-end clone of the Amazon website. It recreates the look and feel of an e-commerce platform, including navigation, product listings, and a structured homepage.

---

## 🚀 Features

* 🧭 Navigation bar with logo and menu
* 🔍 Search bar UI
* 🛍️ Product listings section
* 📱 Responsive design for different screen sizes
* 🎨 Clean and modern UI

---

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript

---

## ⚙️ How to Run

1. Clone the repository
2. Open `index.html` in your browser
